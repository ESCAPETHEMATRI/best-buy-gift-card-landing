# Best Buy Gift Card Offer landing page

A static, responsive landing page for an independent promotional offer. It uses the supplied logo and affiliate URL. The page discloses that the offer is third party and does not claim a guaranteed reward or Best Buy endorsement.

## Deploy with Vercel

1. In Vercel, choose **Add New → Project** and import `ESCAPETHEMATRI/best-buy-gift-card-landing`.
2. Keep **Framework Preset** as **Other** and leave the build command empty.
3. Set the output directory to `.` (the repository root), then deploy.

The page is `index.html`, with `best-buy-logo.png` alongside it.
